# DDR4 Memory Controller Verification

## Overview

This project focuses on the functional verification of a DDR4 Memory Controller using SystemVerilog and the Universal Verification Methodology (UVM).

The verification environment was used to validate the controller's functionality through simulation, assertions, and structured test scenarios.

---

## Objectives

- Verify DDR4 Memory Controller functionality
- Execute UVM-based verification test cases
- Perform protocol checking using SystemVerilog Assertions (SVA)
- Perform simulation and debugging using QuestaSim
